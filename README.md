# WhisperLink

إضافة ووردبريس مستقلة للربط الداخلي بواجهات عربية وفرنسية وإنجليزية. تختار الواجهة لغة الموقع في إعدادات ووردبريس تلقائيًا، وتستخدم الإنجليزية للغات الأخرى. لا تتبع Link Whisper ولا تستخدم شفرته أو علامته. الإصدار 0.2.1 هو أساس وظيفي، وليس تكافؤًا مثبتًا مع المنتج التجاري.

## التثبيت

1. من لوحة ووردبريس: **إضافات ← أضف إضافة ← رفع إضافة**.
2. ارفع `dist/whisperlink-0.1.0.zip` ثم فعّلها.
3. افتح **WhisperLink** واضغط **فحص المحتوى**.
4. راجع الاقتراحات قبل إدراجها. عرّف كلمات مستهدفة عندما لا يتطابق عنوان الصفحة مع النص المراد ربطه.

المتطلبات: WordPress 6.6+، PHP 8.1+ مع `mbstring`، وMySQL/MariaDB. جرّب على نسخة تجريبية مع نسخة احتياطية قبل موقع الإنتاج.

## الوظائف المنفذة

- فهرسة المقالات والصفحات وأنواع المحتوى العامة المختارة، بدفعات من 25 سجلًا.
- عد الروابط الداخلية والخارجية، مصادر الروابط الواردة، الصفحات اليتيمة والصفحات بلا روابط صادرة.
- نسبة تغطية الصفحات بروابط واردة، لا تقدير ترتيب بحث أو عائد مالي.
- اقتراحات واردة وصادرة باستخدام كلمات مخصصة والعناوين وكلمات Yoast وRank Math.
- ترتيب الاقتراحات حسب تشابه الكلمات المحلي، مع معاينة السياق وتعديل نص الرابط وإدراجه.
- قواعد عبارة/وجهة، منع تكرار الوجهة والربط الذاتي، معاينة وتطبيق على مقال، وتطبيق اختياري عند حفظ مدير الموقع.
- فحص HTTP للروابط الداخلية والخارجية عبر WordPress safe HTTP API، مع تخزين النتائج 7 أيام.
- تقارير النطاقات والروابط، تصدير CSV للصفحة المعروضة مع معالجة حقن الصيغ.
- معاينة تغيير URL ثم تطبيقه لكل مقال، مع الحفاظ على fragment إن لم تحدد الوجهة الجديدة واحدًا.
- كلمات مفتاحية يدوية، استثناء صفحات، اختيار أنواع المحتوى، حد روابط القواعد.
- سجل محتوى قبل التعديل وتراجع محمي ببصمة المحتوى. التغييرات الأحدث تمنع التراجع القديم.
- رابط للاقتراحات من صندوق في محرر المقال.
- واجهة عربية RTL متجاوبة، صلاحيات مدير الموقع وnonce لجميع طلبات الإدارة.

## الحدود والفروق عن Link Whisper

| المجال | حالة هذا الإصدار |
|---|---|
| اقتراحات الربط وتقارير المحتوى | منفذة بمحرك محلي قائم على الكلمات؛ ليست ذكاءً اصطناعيًا دلاليًا |
| Gutenberg والمحرر التقليدي | التعديل يحافظ على النص الأصلي وتعليقات الكتل؛ لا يعيد تسلسل المستند |
| Elementor وDivi وshortcodes | لا تُعدّل بيانات منشئات الصفحات أو المستندات ذات shortcodes تلقائيًا |
| جودة وأداء بمستوى Link Whisper | غير مقاسة؛ تحتاج مجموعة محتوى مرجعية واختبار مقارنة |
| اقتراحات AI وإصلاح مكسور بواسطة AI | غير منفذة؛ لا توجد خدمة خارجية أو أرصدة مضمنة |
| Google Search Console | لا يوجد اتصال OAuth أو استيراد بيانات بحث في هذا الإصدار |
| تتبع النقرات | غير منفذ |
| خريطة مرئية تفاعلية للموقع | غير منفذة |
| ربط بين مواقع متعددة، تكاملات منشئات الصفحات | غير منفذة |
| تعديل أرشيف التصنيفات والقوالب والقوائم | غير مدعوم |
| إصلاح تلقائي، تجاهل/تأجيل أخطاء، تتبع سلسلة التحويلات | غير منفذة؛ يوجد فحص حالة وتغيير URL يدوي |

الاقتراحات تبحث في أحدث **500** صفحة مفهرسة وتعرض حتى **40** فرصة. تقارير الصفحات والروابط والسجل مقسمة إلى **50** صفًا. تصدير CSV يشمل النتائج المعروضة فقط. تقرير النطاقات يصل إلى **200** نطاق، ومعاينة تغيير URL إلى **100** مقال. الفحص الدوري يعالج 25 سجلًا و3 عناوين في الساعة؛ زر الفحص يكمل فهرسة المحتوى تباعًا في المتصفح. لا تُعد هذه الحدود مناسبة دون تعديل لمواقع ضخمة أو مقارنة أداء تجارية.

## الخصوصية والتراجع

لا ترسل الإضافة محتوى المقالات إلى أي خدمة. فحص الروابط يرسل طلبات HTTP إلى عناوين المحتوى (الروابط الخارجية معطلة افتراضيًا). لا تُرسل ملفات تعريف ارتباط الموقع. محفوظات التعديل تحتوي النص السابق كاملًا في قاعدة البيانات، ولا تعرضها إلا لمدير الموقع. تعطيل الإضافة يوقف الجدولة، لكنه يحافظ على الروابط والفهارس والسجل. إزالة مجلد الإضافة لا تمس بياناتها؛ الحذف النهائي للجداول ينبغي أن يتم بواسطة مسؤول قاعدة البيانات بعد أخذ نسخة احتياطية.

إضافة الرابط لا تغير الرابط الدائم للمقال. أداة تغيير العناوين تعيد كتابة `href` فقط ولا تنشئ تحويلات 301. «يتيم» هنا يعني لا يوجد مصدر وارد آخر ضمن المحتوى المفهرس، وليس إثباتًا أن محرك البحث لا يستطيع اكتشاف الصفحة.

## بنية المشروع

`whisperlink/` هو المجلد القابل للتثبيت. `tests/` اختبارات المحرك. `.tools/` و`.test-runtime/` بيئات محلية مستثناة من الحزمة. السكربت `build.ps1` ينتج ملف ZIP.

راجع `TESTING.md` لنتائج التحقق وحدود الاختبارات.
